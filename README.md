## 📌 Key Concepts

> JavaScript is single-threaded, but it can handle asynchronous operations through the browser runtime, Web APIs, queues, and the Event Loop.

This repository focuses on understanding **what actually happens when asynchronous JavaScript code runs**, rather than only learning syntax.
